🌐 Parameter 1: External APIs Integration
GET /api/external/weather

Live Open-Meteo weather forecast for campus coordinates and fest outdoor advisories.

GET /api/external/quote

Daily student motivational inspiration quote with author citation.

GET /api/external/holidays

Academic and national holiday calendar for semester planning.

📁 Parameter 3: Express APIs for Local JSON File Storage
GET /api/local/events

Fetches all campus events directly from backend/data/events.json.

GET /api/local/registrations

Reads saved student registrations from backend/data/registrations.json.

GET /api/local/clubs

Fetches active university clubs from backend/data/clubs.json.

🍃 Parameter 4: MongoDB / Mongoose CRUD Operations
GET /api/events

MongoDB Event collection query with sorting, category filters, and search.

POST /api/registrations

Creates student registration, generates custom ID (CC-2026-XXXX), and decrements event seats.

GET /api/clubs

Fetches all student clubs with leader contact info and member counts.
